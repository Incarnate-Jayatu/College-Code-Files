## How to Run

1. Clone the repository

```bash
git clone https://github.com/Incarnate-Jayatu/College-Code-Files.git
```

2. Navigate to this folder

```bash
cd College-Code-Files/Second\ Year/Java\ Programming\ Language
```

3. Compile the program

```bash
javac FileName.java
```

4. Run the program

```bash
java FileName
```
