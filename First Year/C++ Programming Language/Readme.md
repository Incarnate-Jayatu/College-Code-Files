## How to Run

1. Clone the repository

```bash
git clone https://github.com/Incarnate-Jayatu/College-Code-Files.git
```

2. Navigate to this folder

```bash
cd College-Code-Files/First\ Year/C++\ Programming\ Language
```

3. Compile any program

```bash
g++ filename.cpp -o program
```

4. Run the executable

```bash
./program
```
